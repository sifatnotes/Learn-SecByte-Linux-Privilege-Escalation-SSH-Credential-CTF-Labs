## Learning Path

A practical learning path for this collection is:

1. Start with **Coffee After Dark** and **Brewed Shells** to become familiar with the Linux-focused lab environment.
2. Study **Sudo Sleuth 3** and **Sudo Slip: Root via Misconfig** for sudo and configuration-security concepts.
3. Continue with **Bean to Root** for broader Linux privilege-escalation practice.
4. Explore **SSH Key to Root** and **Key Harvest: SSH Secrets** for SSH key and secret-management concepts.
5. Study **Crack the Keychain** and the credential-focused Coffee labs.
6. Finish with **TTY Forge** and **Plugin Dropbox** for additional Linux and application-security practice.

The progression can be adapted according to your existing Linux, networking, and security knowledge.

## How to Use the Labs

1. Choose a lab from the searchable index.
2. Open the corresponding Learn SecByte URL.
3. Read the lab objectives and scope before beginning.
4. Work only inside the authorized lab or CTF environment.
5. Record the vulnerability or security concept you encounter.
6. Focus on understanding the underlying security weakness rather than memorizing steps.
7. Where applicable, consider how the issue could be detected, prevented, or remediated.

For pentesters and security students, useful notes include the affected security control, access boundary involved, evidence observed, and possible defensive mitigation.
